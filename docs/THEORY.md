# Mathematical Foundations of i.i.d. Violation under Duplicate Leakage

Supervised learning assumes training data $S_{tr}$ and test data $S_{te}$ are independent draws from $\mathcal{D}$.
When duplicate tuples cross partition boundaries, $\mathbb{P}(S_{te} \mid S_{tr}) \neq \mathbb{P}(S_{te})$, invalidating the generalization bound.
